# Monsoon Mind and Waterlogging



A waterlogging intelligence, digital twin and risk-aware routing platform for **Bengaluru**.



**Maintainer:** [Rajesh](https://github.com/Rajesh-180807)



## About



Monsoon Mind and Waterlogging helps people understand flood-prone areas during the monsoon and find safer routes. This project is being adapted for Bengaluru.
